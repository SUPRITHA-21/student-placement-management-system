# Student Placement Management System

A web-based application for managing student placements, built with Python, Flask, MySQL, HTML and CSS.

## Features
- Student login and dashboard
- Admin login and dashboard
- Admin can manage placement details
- MySQL database

## Technology
- Python
- Flask
- MySQL
- HTML
- CSS

## Run locally
Create virtual environment:

```
python -m venv venv
```

Windows:

```
venv\Scripts\activate
```

Install dependencies:

```
pip install -r requirements.txt
```

Run:

```
python app.py
```

Open http://127.0.0.1:5000/
